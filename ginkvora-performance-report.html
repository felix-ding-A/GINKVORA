问题清单与修复建议（按优先级）

P1 GTM 容器双重加载 → GA4 事件可能翻倍 + 每页浪费 ~440KB JS

head 内有两套 GTM 加载器：① Cloudflare 首方代理 /hry7/（async，解析即加载，实测返回完整 GTM 容器 JS 442KB）；② 官方直连 https://www.googletagmanager.com/gtm.js?id=GTM-PSMZBB3H（window load + idle + 1.5s 或首次交互触发）。两套之间无互斥保护，容器会执行两遍，GA4 page_view 等事件大概率重复上报，且多下载约 440KB（gzip 后 ~110KB）脚本。

修复方向：二选一 —— 保留首方代理方案（隐私更优，删掉 head 中的延迟直连加载器）；或保留延迟直连方案（把 /hry7/ 加载器从 head 移除）。改完在 GA4 DebugView / GTM Preview 确认 page_view 只触发一次。

P1 HTML 文档体积超标（每页 310–544KB，gzip 后仍 75–104KB）

主因是 113KB 主题 CSS 全量内联进每个页面（位于 head 3% 处，渲染前需完整解析），跨页无法缓存。gzip 后每页仍比行业优秀线（~50KB）高 1.5–2 倍。

修复方向：Astro 构建配置开启"样式外链化"（build.inlineStylesheets: 'auto'/'never' 或 experimental 相关配置），只保留 1.5KB critical CSS 内联，其余输出为带 hash 的 .css 文件 + immutable 缓存。预期每页原始体积下降 100KB+，且后续页面访问可命中缓存。

P1 recaptcha 脚本 render=undefined（联系页 + 产品页）

页面输出 <script src="https://www.recaptcha.net/recaptcha/api.js?render=undefined"> —— 注入 site key 的变量未解析成功，落到字面量 "undefined"。实际表单代码里硬编码了有效 key（6LfauEkt…），所以 grecaptcha 不会初始化，token 恒为 null，提交走无验证码兜底 —— 功能降级但不阻断，同时白加载 ~150KB+ recaptcha 脚本且控制台报错。

修复方向：把真实 site key 注入 script src（修复环境变量引用），或改为"用户点击提交时才动态注入 recaptcha"，把 ~150KB 脚本从首屏移除。

P2 产品列表 85 张卡片图全部缺 width/height → CLS 风险

85 张 Sanity 图均无宽高属性，懒加载图进入视口时卡片高度突变，产生布局偏移（Core Web Vitals 的 CLS 指标受影响）。

修复方向：为 <img> 补 width/height（或外层容器 aspect-ratio 固定比例）。产品卡比例统一（多为 1376×768 / 2400×1792），可统一声明。

P2 Insights 文章正文图：201KB 全尺寸 + 无懒加载 + 经 /media 代理

正文图走 /media/images/… 站点代理返回全尺寸 webp（实际 201KB jpeg），未走 Sanity CDN 裁剪参数，且无 loading=lazy、无宽高。1 张图就顶全页 1/5 体积。

修复方向：正文图改用 Sanity CDN 直链 + ?w=800&auto=format（预期 20–60KB），补 lazy + 宽高。若 /media 是 Vercel 重写，直接改为输出 cdn.sanity.io URL 即可。

P2 TTFB 多地域表现待验证

本机实测 TTFB 2.5–8.5s 偏高，但 Cloudflare 边缘指标显示缓存命中处理仅 18ms/源站 0ms，判定慢在"本机→边缘"链路的代理环境，不代表真实用户。目标市场若在欧美，建议用 GTmetrix/Pingdom 多地域复测；若欧美 TTFB > 1s，可考虑把 Vercel 区域（region）配置贴近目标市场或开启 CF Argo/Smart Placement。

P3 其他次要项

① robots.txt 中 Cloudflare 托管 AI 爬虫禁止块与下方自定义 Allow: / 冲突，建议删掉重复块；② 响应头 Referrer-Policy / X-Frame-Options / X-Content-Type-Options 各重复 3 次，建议只在单一层设置；③ 无 CSP 响应头，鉴于引入 GA/Clarity/recaptcha/Chatwoot/Sanity 多个三方域，建议补一条 allowlist CSP；④ 本地图片文件名含空格，建议规范为连字符；⑤ PSI/CrUX 字段数据（真实用户 LCP/INP/CLS）今日因 API 匿名配额耗尽未取到，建议稍后补跑。
